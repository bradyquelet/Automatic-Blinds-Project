# Automatic Blinds Project

Arduino-based mechatronics project that automates window blinds and room lighting using a photoresistor, PIR motion sensor, DC motor, L293D H-bridge, and addressable LED strip. Project was constrained to 3 weeks class time and a $100 budget.

## Overview
This system uses ambient light levels to raise or lower blinds and uses motion detection to turn on LEDs when the blinds are closed and the room is occupied.
